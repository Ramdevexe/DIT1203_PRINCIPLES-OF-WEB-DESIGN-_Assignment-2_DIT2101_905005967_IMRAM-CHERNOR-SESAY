# Explore Salone
Explore Salone is a website that introduces visitors to Sierra Leone's destinations, local food, and cultural activities. It provides an organized and accessible way to discover places to visit, explore local dining options, and learn more about the country's attractions and traditions.

About the Project

Explore Salone was created to make information about Sierra Leone's attractions, food, and cultural activities easier to explore through a single website.

Finding information about places to visit and things to experience in Sierra Leone can involve searching through different sources. This website brings these topics together in one place, allowing visitors to browse different categories and access additional information about selected destinations, dining options, and activities.

The website features a simple layout with a clean design, organized navigation, and a consistent colour scheme inspired by Sierra Leone's national colours. Its pages are designed to help visitors explore information without making the experience unnecessarily complicated.

Explore Salone focuses on three main areas:

* **Places to Visit:** Discover beaches, islands, wildlife attractions, and historical locations in Sierra Leone.
* **Dining:** Explore local dishes, street food, drinks, and dining spots.
* **Activities:** Learn about cultural celebrations, holidays, and other activities associated with Sierra Leone.

The website also includes an About page that explains its purpose and provides additional information about the project.

Who Is This Website For?

Explore Salone is designed for people who want to learn more about Sierra Leone and explore what the country has to offer.

Its intended audience includes:

* **Visitors and tourists:** People looking for information about destinations and experiences in Sierra Leone.
* **Local residents:** People interested in discovering places to visit, local food, and cultural activities.
* **People interested in Sierra Leonean culture:** Anyone who wants to explore the country's traditions, cuisine, and attractions.
* **Students and general researchers:** People looking for an introductory source of information about selected places and cultural experiences in Sierra Leone.

The website organizes these topics into clear sections, making it easier for visitors to find information relevant to their interests.

How Does It Help Users?

Explore Salone helps users discover information about Sierra Leone through a straightforward browsing experience.

Instead of presenting every topic on one long page, the website separates its content into categories. Visitors can choose the section that interests them and explore relevant information.

The website helps users in several ways:

* **Discover destinations:** Browse information about selected beaches, islands, wildlife attractions, and historical sites.
* **Explore local food:** Find information about Sierra Leonean dishes, snacks, drinks, and dining locations.
* **Learn about cultural activities:** Explore selected celebrations, holidays, and activities associated with the country.
* **Access additional details:** Open individual information pages to learn more about selected destinations, dining options, and activities.
* **Navigate easily:** Use the main navigation menu to move between the website's different sections.
* **Explore information visually:** View photographs alongside relevant content to make the browsing experience more engaging.

By bringing these topics together, Explore Salone provides a convenient starting point for learning about Sierra Leone's attractions, cuisine, and cultural experiences.

Key Features

1. Homepage

The homepage introduces Explore Salone and provides an entry point to the website's main content.

It uses a two-column hero layout to combine introductory text with a featured image. Links help visitors move towards relevant sections of the website.

### 2. Places to Visit

The Locations section presents selected destinations across Sierra Leone.

Featured destinations include:

* Lumley Beach
* Tokeh Beach
* River Number Two Beach
* Bureh Beach
* Tacugama Chimpanzee Sanctuary
* Tiwai Island
* Bunce Island
* Outamba-Kilimi National Park

Visitors can browse the destinations and open their individual information pages to explore additional details.

3. Dining

The Dining section introduces visitors to local food, drinks, and dining experiences in Sierra Leone.

Its content includes topics such as:

* Traditional Sierra Leonean dishes
* Street food and snacks
* Local drinks
* Fresh grilled fish
* Beachfront dining
* Dining experiences around popular coastal destinations

Individual dining information pages provide a more focused way to explore selected topics.

4. Activities and Cultural Information

The Activities section provides information about selected celebrations and cultural activities.

Examples include:

* Independence Day
* Christmas
* Armed Forces Day

Visitors can select an activity to access its dedicated information page.

5. Individual Information Pages

Explore Salone uses separate information pages for selected locations, dining topics, and activities.

These pages allow the website to present additional details without overcrowding the main category pages. They also provide a consistent way to navigate between general listings and more specific information.

6. Navigation Menu

The website includes a navigation menu that connects its main sections:

* Home
* Locations
* Dining
* Activities
* About Us

This consistent navigation helps visitors move between sections without needing to return to the homepage each time.

7. Search Interface

The website includes a search interface with an input field and a search button, providing a way for visitors to interact with the search feature.

The search interface is styled to match the website's overall design.

8. Responsive Layout

The website uses responsive layout techniques, including flexible containers, CSS Grid, and Flexbox.

These techniques help the page layout adapt to different screen sizes and keep the content organized across supported devices.

9. Image-Based Content

Photographs accompany selected destinations, dining topics, and other content.

The images help visitors connect the information they read with the places and experiences being presented. The project also includes a `CREDITS.txt` file documenting image sources and reuse information.

Some photographs are loaded from Wikimedia Commons, so an internet connection is required to retrieve those images.

10. Consistent Visual Design

The website uses a consistent visual style across its pages.

Its design includes:

* A muted colour palette inspired by Sierra Leone's national colours.
* Clear headings and readable text.
* Light backgrounds and structured content sections.
* Consistent spacing and alignment.
* Buttons and links that help visitors navigate the website.
* A shared header and footer design.

These elements help create a recognizable appearance and make the content easier to browse.

Technologies Used

Explore Salone is built using the following web technologies:

* **HTML5:** Provides the structure and content of the website, including headings, navigation, images, links, and information sections.
* **CSS3:** Controls the website's appearance, including colours, typography, spacing, layouts, and responsive styling.
* **JavaScript:** Supports the website's interactive functionality and dynamic content where implemented.

The HTML files contain embedded CSS and JavaScript, allowing the website's structure, styling, and interactive behaviour to be maintained within the individual pages.

The project does not require a separate CSS framework or JavaScript framework to open the website locally.

How to View the Website

You can view Explore Salone directly in a web browser without installing a development framework.

Option 1: Download the Repository

1. Open the Explore Salone repository on GitHub.
2. Select the **Code** button.
3. Choose **Download ZIP**.
4. Extract the downloaded repository to a folder on your computer.
5. Open the extracted project folder.
6. Locate the `index.html` file.
7. Double-click `index.html` to open the homepage in your default web browser.

Once the homepage opens, use the navigation menu to explore the other sections.

**File descriptions:**

  File                     Purpose                                                          
  `index.html`             Homepage and introduction to Explore Salone.                     
  `about.html`             Information about the website and its purpose.                    
  `locations.html`         Main page for browsing destinations in Sierra Leone.              
  `locations_info.html`    Additional information about selected destinations.               
  `dinning.html`           Main page for browsing dining topics and local food experiences.  
  `dinning_info.html`      Additional information about selected dining topics.              
  `activities.html`        Main page for browsing cultural activities and celebrations.      
  `activities_info.html`   Additional information about selected activities.                 
  `CREDITS.txt`            Image sources, attribution details, and reuse notes.              

The filenames `dinning.html` and `dinning_info.html` intentionally use the spelling included in the project files. Keep these filenames unchanged unless you also update the links that refer to them.

**Important:** Keep all the HTML files together in the same project folder so that the website's internal links continue to work correctly.

An internet connection is recommended for loading externally hosted photographs. The website's local HTML pages can otherwise be opened directly in a browser.
